# 深海来信 · Into the Abyss

从海面一路下潜到 11000 米，深度、光照、压强与生物随之改变。

## 核心互动

滚动即下潜，固定深度计与生物剪影实时联动。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建产物输出到 `dist/`，使用相对路径 `base: './'`，可部署到 GitHub Pages 的任意子路径。

## 技术栈

Vue 3 · TypeScript · Vite · CSS / SVG / Canvas（本作全部视觉为原创代码绘制，无外部图片与付费 API 依赖）。
